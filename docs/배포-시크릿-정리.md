# GitHub Actions 시크릿 정리

현재 배포 구조는 다음과 같습니다.

- `focus-server`: Spring Boot + Redis가 올라간 EC2로 배포
- `focus-fast-api`: FastAPI + MediaMTX가 올라간 EC2로 배포
- 두 EC2는 같은 VPC 안에서 `private IP`로 통신

## 1. focus-fast-api 레포 시크릿

워크플로우 파일: `.github/workflows/deploy.yml`

필수 시크릿:

| 시크릿 이름 | 예시 값 | 용도 |
|---|---|---|
| `DOCKER_USERNAME` | `your-dockerhub-id` | Docker Hub 로그인 및 이미지 push |
| `DOCKER_PASSWORD` | `dckr_pat_xxx` | Docker Hub 비밀번호 또는 Access Token |
| `EC2_HOST` | `13.125.126.120` | FastAPI EC2 퍼블릭 IP 또는 DNS |
| `EC2_USERNAME` | `ubuntu` | EC2 SSH 유저 |
| `EC2_SSH_KEY` | `-----BEGIN OPENSSH PRIVATE KEY----- ...` | FastAPI EC2 접속용 private key 본문 |
| `REDIS_URL` | `redis://172.31.38.55:6379/0` | Spring/Redis EC2의 Redis private endpoint |
| `HLS_PUBLIC_BASE_URL` | `http://13.125.126.120:8000/hls` | FastAPI가 외부에 내려줄 HLS base URL |

생성되는 `.env` 예시는 아래와 같습니다.

```env
FULL_IMAGE_NAME=your-dockerhub-id/focus-fast-api:<sha>
REDIS_URL=redis://172.31.38.55:6379/0
HLS_PUBLIC_BASE_URL=http://13.125.126.120:8000/hls
```

주의:

- `REDIS_URL`은 `public IP`가 아니라 `private IP` 기준으로 넣는 것이 맞습니다.
- 나중에 CDN/S3로 전환하면 `HLS_PUBLIC_BASE_URL`도 CDN 주소로 바뀝니다.

## 2. focus-server 레포 시크릿

워크플로우 파일: `focus-server/.github/workflows/deploy.yml`

필수 시크릿:

| 시크릿 이름 | 예시 값 | 용도 |
|---|---|---|
| `DOCKER_USERNAME` | `your-dockerhub-id` | Docker Hub 로그인 및 이미지 push |
| `DOCKER_PASSWORD` | `dckr_pat_xxx` | Docker Hub 비밀번호 또는 Access Token |
| `EC2_HOST` | `3.35.202.126` | Spring EC2 퍼블릭 IP 또는 DNS |
| `EC2_USERNAME` | `ubuntu` | EC2 SSH 유저 |
| `EC2_SSH_KEY` | `-----BEGIN OPENSSH PRIVATE KEY----- ...` | Spring EC2 접속용 private key 본문 |
| `RDS_HOSTNAME` | `focus-db.xxxxx.ap-northeast-2.rds.amazonaws.com` | PostgreSQL RDS 주소 |
| `RDS_USERNAME` | `focus_user` | DB 계정 |
| `RDS_PASSWORD` | `********` | DB 비밀번호 |
| `KAKAO_CLIENT_ID` | `********` | 카카오 OAuth 클라이언트 ID |
| `KAKAO_CLIENT_SECRET` | `********` | 카카오 OAuth 클라이언트 시크릿 |
| `JWT_SECRET` | `base64-encoded-secret` | JWT 서명 키 |
| `FASTAPI_BASE_URL` | `http://172.31.38.193:8000` | FastAPI EC2 private endpoint |

생성되는 `.env` 예시는 아래와 같습니다.

```env
FULL_IMAGE_NAME=your-dockerhub-id/focus:latest
RDS_HOSTNAME=focus-db.xxxxx.ap-northeast-2.rds.amazonaws.com
RDS_USERNAME=focus_user
RDS_PASSWORD=********
KAKAO_CLIENT_ID=********
KAKAO_CLIENT_SECRET=********
JWT_SECRET=base64-encoded-secret
EC2_HOST=3.35.202.126
FASTAPI_BASE_URL=http://172.31.38.193:8000
```

주의:

- `FASTAPI_BASE_URL`은 반드시 FastAPI EC2의 `private IP`로 넣는 것을 권장합니다.
- `EC2_HOST`는 현재 워크플로우에서 `.env`에도 같이 쓰고 있지만, 앱 런타임에서 직접 필요하지 않으면 나중에 정리 가능합니다.

## 3. 시크릿 등록 체크리스트

1. 두 레포 모두 `DOCKER_USERNAME`, `DOCKER_PASSWORD` 등록
2. 각 레포에 맞는 `EC2_HOST`, `EC2_USERNAME`, `EC2_SSH_KEY` 등록
3. `focus-server`에는 DB/JWT/Kakao 관련 시크릿 등록
4. `focus-fast-api`에는 `REDIS_URL`, `HLS_PUBLIC_BASE_URL` 등록
5. `focus-server`의 `FASTAPI_BASE_URL`은 FastAPI EC2 `private IP`로 등록

## 4. 권장 운영 메모

- 운영에서는 Docker Hub 비밀번호 대신 `Access Token` 사용 권장
- SSH 키는 배포 전용 키로 분리 권장
- 장기적으로는 EC2 SSH 배포 대신 ECR + SSM 또는 CodeDeploy로 전환 검토
